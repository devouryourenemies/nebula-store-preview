# Nebula Website

Premium Next.js + Tailwind marketing / e-commerce scaffold for Nebula, a premium health, youth, and longevity peptide brand.

## Stack
- Next.js 14 App Router
- TypeScript
- Tailwind CSS

## Included pages
- Landing page with age verification gate
- Product catalog
- Individual product pages
- About
- Lab Testing / COA
- Contact
- Cart placeholder

## Notes
- Static product data only
- No backend or checkout wired yet
- Site-wide compliance disclaimer included: For research use only — not for human consumption.

## Run after installing dependencies
```bash
npm install
npm run dev
```
